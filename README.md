## 📌 Project Status

**Status:** ✅ Working Prototype / Android-Ready

VMT is currently a functional personal finance management application with the core features implemented and packaged as an Android-ready Capacitor project.

The project is actively maintained and may receive future improvements, feature additions, UI enhancements, and security updates.

### Current Version

**V1.0 — Android-Ready Prototype**

### Current Capabilities

- ✅ Income and expense tracking
- ✅ Transaction management
- ✅ Dashboard and financial summaries
- ✅ Budget management
- ✅ Calendar-based transaction view
- ✅ Wallet and savings tracking
- ✅ Financial insights and charts
- ✅ Passcode-based application lock
- ✅ Local data storage
- ✅ CSV export
- ✅ JSON backup and restore
- ✅ Legacy data import
- ✅ Android application support through Capacitor
- ✅ Git/GitHub version control
